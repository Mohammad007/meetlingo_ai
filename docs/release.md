# Release preparation

## 1. Signing key (once)

```bash
keytool -genkeypair -v -storetype PKCS12 -keystore meetlingo-release.jks -alias meetlingo -keyalg RSA -keysize 2048 -validity 10000
```

Keep the keystore and passwords outside git (`*.jks` is ignored). Options:

- **EAS (recommended with CNG):** `npx eas-cli@latest credentials` → upload the keystore, then `npx eas-cli@latest build -p android --profile production`.
- **Local Gradle:** add a small config plugin that writes `signingConfigs.release` into `android/app/build.gradle` from environment variables (`MEETLINGO_STORE_FILE`, `MEETLINGO_STORE_PASSWORD`, `MEETLINGO_KEY_ALIAS`, `MEETLINGO_KEY_PASSWORD`). Don't hand-edit `android/`: it is regenerated by prebuild.

## 2. Versioning

Bump `expo.version` and `expo.android.versionCode` in `app.json`.

## 3. Build

```bash
npm ci
npm run typecheck && npm run lint && npm test
npm run prebuild
cd android && ./gradlew bundleRelease   # .aab for Play; assembleRelease for an .apk
```

`buildArchs` is `arm64-v8a` and `x86_64` (emulator). For a Play-only build you can drop `x86_64` to save about 30 MB.

## 4. Play Console declarations

- Foreground service types: **microphone** (live captioning the user started) and **mediaProjection** (optional same-phone playback capture). Provide a short video of starting a meeting and the notification.
- Data safety: no data collected or shared. Audio and transcripts are processed and stored only on the device.
- Permissions: `SYSTEM_ALERT_WINDOW` is optional (floating captions).
- Third-party model licences: see `docs/model-licenses.md`. Resolve the CC-BY-SA question for the default model first.

## 5. Real-device acceptance checklist

Run on at least one mid-range ARM64 phone (Android 12–15):

- [ ] Fresh install → onboarding → permissions → both models download, verify, and show sizes/dates.
- [ ] Airplane mode on: a physical meeting produces English interim, final and Hinglish captions.
- [ ] Wi-Fi on: same behaviour; no account or server prompts.
- [ ] Pause: mic indicator off, notification shows "Paused"; Resume continues with correct timestamps.
- [ ] Stop (in-app and notification): mic released, notification removed, overlay closed, transcript opens.
- [ ] 30- and 60-minute sessions: no gaps in saved segments. Note RTF, dropped frames, battery and temperature from Diagnostics.
- [ ] Screen off and app in background for 10 min: captions are saved. Swiping the app away stops the session and marks it as stopped.
- [ ] Force-stop during a meeting: on relaunch the meeting shows as **interrupted**, with saved captions.
- [ ] Revoke the mic permission mid-meeting: capture stops with an explanation.
- [ ] Start a phone call during a meeting: `mic_silenced` / mic-busy messaging appears.
- [ ] Laptop speakers at 60–80% volume, 0.5 m away: captions are usable. With laptop headphones: the no-audio warning appears.
- [ ] Same-phone compatibility test with YouTube (expect "supported") and with a Meet/Zoom call (expect "can't be captured").
- [ ] Glossary terms (API, APK, dashboard, React Native) stay in English in Hinglish output.
- [ ] Search finds English and Hinglish text. Editing a correction updates search and exports.
- [ ] TXT, SRT and PDF exports open correctly when shared and when saved to a folder.
- [ ] Delete meeting, delete all data and retention all work. Model delete is blocked during a meeting.
- [ ] TalkBack labels on the main controls. 360 dp phone, landscape, and tablet layouts.
